# Worker Library / 操作员家族

Choose one worker family per image. Rename the worker in the user's language when useful, but keep the visual DNA consistent.

## Universal Workers

### Router / 走线工

Use for connection, sequence, handoff, route, dependency, feedback, or relationship.

Actions: route, bridge, bridge, untangle, carry, trace.

Tools: copper carrier trace, via, bus bar, bridge connector, solder bridge.

### Sensor / 传感工

Use for attention, evidence, inspection, hidden mechanism, criticism, comparison, or quality.

Actions: sense, detect, probe, compare, isolate, highlight.

Tools: probe pin, test lead, sensor array, oscilloscope screen, signal indicator.

### Switcher / 开关工

Use for boundary, permission, filtering, approval, rejection, threshold, or transformation.

Actions: switch, open, filter, toggle, block, convert.

Tools: relay, logic gate, MOSFET switch, filter capacitor, threshold comparator.

## AI And Machine Learning Workers

### Trainer / 训练工

Use for model training, loss optimization, gradient descent, weight updates, or convergence.

Actions: calibrate, tune, adjust, iterate, converge, power.

Tools: loss curve display, weight matrix tray, gradient probe, learning rate dial, epoch counter.

### Feature Hunter / 特征猎手

Use for feature engineering, representation learning, attention, hidden patterns, or embedding.

Actions: sense, extract, map, isolate, amplify, encode.

Tools: feature probe, attention heatmap card, embedding vector strip, dimension reducer.

### Debugger / 调试工

Use for failure modes, error analysis, debugging, anomaly detection, or loop repair.

Actions: debug, trace, isolate, repair, patch, ground.

Tools: logic analyzer, breakpoint probe, error signal tracer, patch wire, ground clip.

## Business, Product, And Data Workers

### Pipeline Builder / 管道工

Use for data pipelines, ETL, workflow, sequence, handoff, or system architecture.

Actions: route, bridge, pipe, merge, split, carry.

Tools: pipe connector, junction box, merge manifold, split tee, flow meter.

### Metric Amplifier / 指标放大工

Use for metrics, KPIs, growth, dashboards, or signal amplification.

Actions: amplify, boost, measure, compare, display, calibrate.

Tools: op-amp module, gain dial, display panel, comparator chip, reference voltage.

### Tradeoff Bridge / 权衡桥接工

Use for decision, economics, priority, ethics, tradeoffs, and strategy.

Actions: bridge, balance, compare, modulate, switch, weigh.

Tools: bridge circuit, differential amplifier, balance network, modulator, weight register.

## Human And Life Workers

### Shield / 屏蔽工

Use for personal boundaries, protection, noise filtering, self-care, or fragility.

Actions: shield, filter, ground, absorb, isolate, protect.

Tools: shield can, filter capacitor, ground plane, Faraday cage, noise absorber.

### Memory Keeper / 记忆工

Use for memory, nostalgia, archive, cultural lineage, or personal history.

Actions: encode, store, retrieve, preserve, decode, read.

Tools: memory chip, shift register, storage cell, address decoder, read head.

### Clock Keeper / 时钟工

Use for time, waiting, rhythm, cycles, patience, or periodic events.

Actions: clock, time, pace, wait, trigger, synchronize.

Tools: crystal oscillator, clock tree, timer chip, cycle counter, phase detector.

## Two-Worker Scenes

Use two workers only when the relation is between two parties and one worker would hide the structure: negotiation, tension, mirrored comparison, handoff, or mutual dependency.

Rules:

- Keep one focal action.
- Keep both workers soldering-cap robots and smaller than the relationship object; each may carry its own simple LED state (e.g. one amber, one green).
- Let each worker hold one side of the relation: differential probe, bridge arm, relay pair, or shared bus.
- Do not turn the image into a cast of characters.

Regenerate if the two workers only add charm, conversation, or symmetry without clarifying the relation.
