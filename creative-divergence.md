# Creative Divergence / 创意发散

Use this reference when the image has the right circuit style but the metaphor feels habitual.

The goal is not novelty. The goal is precision: find the circuit world that fits this source anchor, this relationship, and this reader intent better than the defaults.

## Why Diverge

Prototype-lock is the root of the boring feeling.

The common locks are:

- mainboard (large flat board with chips)
- breadboard (prototyping grid)
- server rack (stacked boards)

These worlds are useful, but they become weak when they appear before the article has made its own demand.

Prototype-lock fails because:

- the metaphor fits Circuit Workers more than the article
- the primary relationship collapses into a familiar board layout
- domain-specific components and textures disappear
- emotional temperature becomes generic calm
- the reader feels a template instead of an interpretation

Diverge first. Converge second.

Precision beats novelty. A familiar mainboard is correct when the article is truly about system architecture. A fresh metaphor is only better when its circuit world renders the relation more exactly.

## Divergence Method

Start from one source anchor.

```text
source anchor:
reader intent:
primary relationship:
domain:
emotional temperature:
default metaphor risk:
```

Generate 3-5 directions before writing the final prompt.

Each direction must change at least one angle:

- worker family
- domain lens
- circuit metaphor world
- emotional temperature
- composition mode

Outline each direction in one line.

```text
direction:
- metaphor world:
- worker family:
- relationship rendered:
- one-line scene:
- why it fits:
- risk:
```

Score quickly:

| Criterion | Question |
| --- | --- |
| Content precision | Does the world fit the specific source anchor? |
| Relationship clarity | Does it show direction, condition, and state? |
| Intent fit | Does it serve explain, feel, trust, decide, or remember? |
| Domain specificity | Does it belong to this topic's world? |
| Freshness | Does it escape defaults without becoming random? |
| Simplicity | Can the reader understand it in three seconds? |

Choose the direction with the strongest fit, not the strangest premise.

## Divergence Library

Use this menu to break prototype-lock. Map loosely to `references/relationship-grammar.md`; choose by relationship first.

### AI Training Board

Transformation, sequence, dependency, feedback. Use GPU modules, loss curve displays, weight matrix trays, gradient probes, epoch counters, learning rate dials.

### Sensor Network

Boundary, containment, feedback, contrast, fragile signal. Use scattered sensor nodes, antenna arrays, signal strength bars, noisy channels, clean/dirty signal paths.

### Power Supply Unit

Dependency, causality, hierarchy, energy flow. Use voltage regulators, transformer stages, filter capacitors, load indicators, brownout flags, surge protectors.

### FPGA Fabric

Hierarchy, connection, reconfiguration, parallelism. Use configurable logic blocks, routing channels, switch matrices, bitstream labels, partial reconfiguration zones.

### RF Front End

Signal, noise, filtering, amplification, tuning. Use antenna traces, filter banks, LNA stages, mixer nodes, frequency labels, noise floor indicators.

### Memory Board

Storage, retrieval, archive, lineage, persistence. Use DRAM arrays, address decoders, read/write heads, bank selectors, refresh counters, retention flags.

### Motor Driver

Control, feedback, power delivery, protection. Use H-bridge stages, current sensors, PWM generators, encoder inputs, stall detectors, thermal flags.

### Audio Codec

Signal processing, filtering, conversion, quality. Use ADC/DAC stages, sample rate labels, filter coefficients, dynamic range indicators, clipping flags.

### Clock Distribution

Timing, synchronization, phase, rhythm. Use crystal oscillators, PLL loops, clock trees, phase detectors, jitter indicators, skew markers.

### Debug Probe Station

Inspection, evidence, failure analysis, diagnosis. Use logic analyzer channels, trigger settings, waveform displays, breakpoint markers, protocol decoders.

### IoT Gateway

Routing, filtering, protocol translation, boundary. Use protocol bridges, packet filters, secure elements, connection managers, throughput meters.

### Analog Computing

Continuous value, approximation, tradeoff, precision. Use op-amp stages, resistor ladders, analog multipliers, precision references, drift indicators.

### Quantum Processor

Superposition, entanglement, measurement, probability. Use qubit cells, coupling resonators, measurement readout, coherence indicators, error correction flags.

### Neural Interface

Biological-digital bridge, signal extraction, adaptation. Use electrode arrays, signal conditioners, feature extractors, adaptation loops, biometric labels.

### Legacy Upgrade Board

Before/after, migration, compatibility, transformation. Use old and new component generations, adapter sockets, migration traces, compatibility flags, version labels.

## Convergence Criteria

After divergence, converge hard. Do not keep five ideas alive in one image.

Pick the direction that is:

1. most precise to the specific content
2. most fit to the inferred intent
3. clearest about the primary relationship
4. most distinct from defaults already used
5. simplest without flattening the idea

Use `references/intent-reading.md` to infer whether the user wants explanation, emotion, prestige, critique, persuasion, or memory.

Use `references/variation-engine.md` after the world is chosen: vary camera, state coding, labels, worker LED expression, and component rhythm without changing the core metaphor.

Use `references/composition-modes.md` after convergence to choose the layout: single focal scene, one-board multi-step pipeline, split-board comparison, cutaway, loop, or chained route.

## One-Board Multi-Step Rule

When several beats happen in one system, do not automatically split them into a series.

Use one-board multi-step composition when:

- the same board, chip, or pipeline contains all steps
- the reader must compare steps spatially, not only chronologically
- the final beat changes the meaning of earlier beats
- a repeated trace, loop, or crossing is the core idea

Good examples:

- four processing stages on one AI pipeline board
- three revisions on one debug probe station
- five filter stages around one signal path
- a feedback loop returning to the same comparator

Regenerate if it becomes four disconnected mini-panels. The point is one board with several visible beats, not a comic strip disguised as a circuit.

## Accept / Regenerate

Accept if:

- 3-5 circuit worlds were considered before the final prompt
- the chosen world fits the source anchor more precisely than the defaults
- the primary relationship is visible in components, traces, and state coding
- domain components, materials, palette, and labels belong to the article
- novelty never outruns clarity
- the composition has one focal module or one readable board
- the worker physically performs the relation inside the chosen world
- short labels are attached to components, traces, relays, sensors, or state markers

Regenerate if:

- the scene defaults to mainboard / breadboard / rack without proving fit
- the metaphor is fresh but unrelated to the source anchor
- candidates differ only by decoration, not by relationship or domain lens
- the image reads as a flat schematic with PCB texture
- the worker is decorative after the metaphor world is chosen
- the user intent is ignored for a clever visual premise
- a multi-step composition is crowded, disconnected, or unreadable at a glance
