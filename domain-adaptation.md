# Domain Adaptation / 领域适配

How to adapt circuit workers to different article domains. The board's components, palette accent, and tool choice must belong to the article's world, not force engineering props into every topic.

## AI / Machine Learning

Worker families: Trainer, Feature Hunter, Debugger, Pipeline Builder, Metric Amplifier.

Board world: AI training board with GPU modules, loss curve displays, weight matrix trays, gradient probes, epoch counters, attention heatmap cards, embedding vector strips.

Accent color: deep learning purple or neural blue.

Typical components: GPU chip, loss display, weight register, gradient probe, attention module, embedding strip, batch buffer, learning rate dial.

Labels: 训练, 损失, 权重, 梯度, 注意力, 嵌入, 批次, 学习率, 收敛, 过拟合, 推理, 微调.

Tools: gradient probe, loss curve reader, weight calibrator, attention lens, feature extractor.

## Engineering / Software

Worker families: Router, Debugger, Pipeline Builder, Switcher, Shield.

Board world: mainboard or debug station with logic analyzer channels, breakpoint probes, protocol decoders, signal tracers, stack registers.

Accent color: code green or debug amber.

Typical components: processor chip, debug port, logic analyzer, breakpoint register, stack trace, protocol decoder, error flag, watchdog timer.

Labels: 编译, 链接, 运行时, 调试, 断点, 堆栈, 协议, 错误, 看门狗, 中断, 线程, 队列.

Tools: logic analyzer clip, breakpoint probe, signal tracer, patch wire, ground clip.

## Business / Product

Worker families: Pipeline Builder, Tradeoff Bridge, Metric Amplifier, Switcher, Router.

Board world: business dashboard board with metric displays, comparator chips, pipeline connectors, switch matrices, KPI indicators.

Accent color: growth green or strategy gold.

Typical components: metric display, comparator, pipeline connector, switch matrix, KPI LED, funnel capacitor, conversion register, retention counter.

Labels: 转化, 留存, 漏斗, 权衡, 决策, 增长, 指标, 路径, 优先级, 成本, 收益, 阈值.

Tools: metric probe, comparator input, switch toggle, funnel filter, gain dial.

## Education / Science

Worker families: Sensor, Trainer, Clock Keeper, Memory Keeper, Feature Hunter.

Board world: lab instrument board with sensor modules, calibration references, timing crystals, storage cells, measurement probes.

Accent color: knowledge teal or experiment blue.

Typical components: sensor module, calibration reference, crystal oscillator, storage cell, measurement probe, hypothesis gate, evidence LED, concept register.

Labels: 假设, 证据, 实验, 校准, 概念, 知识, 测量, 验证, 发现, 原理, 推理, 结论.

Tools: calibration probe, measurement lead, sensor array, evidence detector, knowledge encoder.

## Finance / Economics

Worker families: Tradeoff Bridge, Metric Amplifier, Switcher, Shield, Clock Keeper.

Board world: trading desk board with high-speed comparators, signal amplifiers, risk indicators, timing crystals, and shield cans.

Accent color: market gold or risk amber.

Typical components: high-speed comparator, signal amplifier, risk LED, timing crystal, shield can, order register, price DAC, volatility gauge, portfolio bus.

Labels: 风险, 收益, 波动, 杠杆, 对冲, 仓位, 止损, 估值, 周期, 信号, 噪声, 趋势.

Tools: risk probe, gain dial, timing reference, shield filter, volatility meter.

## Culture / Art / Personal Essay

Worker families: Shield, Memory Keeper, Clock Keeper, Feature Hunter, Sensor.

Board world: softer analog board with memory cells, clock crystals, signal conditioners, noise filters, and warm LED accents. Less digital, more analog warmth.

Accent color: memory warm white or essay rose.

Typical components: memory cell, clock crystal, signal conditioner, noise filter, warm LED, resonance inductor, trace keeper, analog switch, envelope detector.

Labels: 记忆, 时间, 共鸣, 信号, 噪声, 留白, 频率, 延迟, 回响, 保护, 温度, 节奏.

Tools: memory probe, clock reader, signal conditioner, noise filter, resonance tuner.

Important: for culture/art/personal essay domains, soften the circuit metaphor. Use analog, warm, and organic-sounding components rather than digital, fast, and cold ones. The board should feel like a memory palace, not a server room.

## Lifestyle / Health

Worker families: Shield, Clock Keeper, Sensor, Memory Keeper.

Board world: wearable or biosensor board with electrode arrays, vital sign displays, circadian timers, protection circuits, and comfort indicators.

Accent color: health mint or comfort lavender.

Typical components: electrode array, vital sign display, circadian timer, protection circuit, comfort LED, stress gauge, sleep register, activity counter.

Labels: 睡眠, 压力, 节律, 保护, 恢复, 活力, 休息, 运动, 饮食, 情绪, 边界, 呼吸.

Tools: vital probe, circadian reader, stress gauge, comfort filter, recovery amplifier.

## Blending Rules

- When an article spans two domains, let the primary domain choose the board world and the secondary domain choose the accent components. An AI article about creative writing uses the AI board world with a few memory/clock accent components from the Culture domain.
- Never paste full secondary-domain components as decoration. Each accent component must carry a meaning.
- The palette accent should come from the primary domain. The worker's tool can borrow from the secondary domain when it performs the cross-domain action.
